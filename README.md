# RAWER 0.6.2 для Windows

**[Скачать RAWER для Windows x64](https://github.com/malekuloman-ship-it/nikonrawer/releases/download/v0.6.2/RAWER-0.6.2-Windows-x64.zip)** · [Исходники](https://github.com/malekuloman-ship-it/nikonrawer/releases/download/v0.6.2/RAWER-0.6.2-source.zip)

RAWER уменьшает размер Nikon ZR 6K R3D-NE приблизительно в **2×** или **4×**, сохраняя разрешение, RAW-настройки камеры, звук и таймкод. Сжатие выполняется с потерями; итоговый размер и качество зависят от материала.

Автор: **Александр Шичанин**.

## Запуск

Требуется Windows x64 с .NET Framework 4.x. Распакуйте Windows-архив целиком и откройте **RAWER.exe**. Установка и аккаунт не нужны.

1. Добавьте R3D-файлы или папку в панель «Исходники».
2. Выберите 2× или 4× и папку для готовых файлов.
3. Нажмите «Сжать». Результаты появятся в четвёртой панели; оттуда их можно открыть в Проводнике.

Обработка локальная. Оригиналы не перезаписываются, рядом с готовой копией создаётся технический `.report.json`. Выбранные папки и режим сохраняются локально в `%LOCALAPPDATA%\RAWER\settings.json`.

Проверен профиль Nikon ZR 6K NR3D с техническим растром 6060 × 3410. Другие камеры и режимы не подтверждены. Сохраняйте оригиналы и проверяйте качество в редакторе. Метаданные камеры сохраняются: программа не обезличивает съёмку.

## Лицензии и исходники

Декодер и геометрия полос адаптированы из [dnglab](https://github.com/nbuchwitz/dnglab/tree/nikon-he-jpegxs/rawler/src/decompressors/jpegxs), GNU LGPL 2.1. Уведомления и полный текст лицензии находятся в `third_party/`. Энкодер и повторное квантование реализованы для RAWER.

Полные исходники этой версии, ресурсы и скрипт сборки доступны отдельным архивом **RAWER-0.6.2-source.zip** на [той же странице релиза](https://github.com/malekuloman-ship-it/nikonrawer/releases/tag/v0.6.2). Для сборки распакуйте архив исходников и выполните `powershell -File .\build.ps1`; готовая программа появится в `dist/RAWER-0.6.2/`.

Иллюстрации интерфейса созданы с помощью генератора изображений; сведения об их происхождении сохранены.
